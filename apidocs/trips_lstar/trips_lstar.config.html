_interpret_data_dictionary_and_set_attributes()

interpret user-specified values from a config file, such as ‘y’ and ‘n’, as Python types these values have already been loaded into a data dictionary attribute in some cases, we set the attributes directly from the data dictionary otherwise, we modify the values, then set attributes from all the values at the end important: the Keywords.data_dic dictionary must have values that are writable to a file after typecasting with str(…)

for example, str(True) = ‘True’, so boolean values are OK
